# Product

## Register

brand

## Platform

cli

## Users

People who want a calm local calendar — a few events, visible today/this week —
without cloud accounts, sync, or SaaS chrome — from the terminal as `oca`.

## Product Purpose

optionCalendar is a minimal local calendar: one ICS file under `~/.option/cal/`,
`add` / `ls` / `today` / `week` / `month` / `import`, an explicit `tui` month +
agenda view, and `config` for settings — plus an optional bridge
that surfaces Markdown tasks with due dates inside `today`.

Bare `oca` prints help unless opted in: `launch_tui_on_no_args`
(`oca config --launch-tui-on-no-args true`) opens the TUI instead.

## Positioning

Quiet dates on your disk — today, this week, this month.

## Brand Personality

Exact, local, unhurried — never purple SaaS.

## One-liner

Minimal local calendar over one ICS file — quiet Option family CLI.
